## Do arquivo à tela

Este parágrafo vem de `content/paginas/boas-vindas.mdx`. O título e a abertura acima vêm do **frontmatter** deste mesmo arquivo.

1. O leitor encontra a coleção no `cms/estrutura.json`.
2. O `gray-matter` separa o YAML do corpo.
3. O Next.js carrega o documento no servidor.
4. O React monta a página e o `MDXRemote` renderiza este texto.

## Conteúdo editável

> Altere este texto e o campo `title` no arquivo MDX. Recarregue a página e observe onde cada mudança aparece.

Este documento usa Markdown no corpo, seguindo o fluxo de edição do Webtech Editor. Os componentes React da aplicação definem sua apresentação.
